# Product architecture decisions

The product's own Architecture Decision Records ([0035](../adr_v2/0035-products-derived-from-the-skeleton.md)), numbered from 0001 in the format of [0019](../adr_v2/0019-adr-convention.md). They refine the skeleton's decisions in `docs/adr_v2/` for this product and never contradict them; a skeleton decision that has to change is changed in the skeleton. Diagram pages go in `diagrams/`, with an index of their own as the skeleton's [diagrams](../adr_v2/diagrams/README.md) have.

In the skeleton this directory holds only this file. A product rewrites it as its index.
